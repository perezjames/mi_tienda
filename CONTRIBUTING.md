# Cómo Contribuir

¡Gracias por tu interés en contribuir a **Mi Tienda**! 🎉

Nos encanta recibir ayuda, ya sea reportando bugs, sugiriendo nuevas funcionalidades o enviando código. Aquí tienes algunas pautas para hacerlo más fácil.

## ¿Cómo puedo ayudar?

### 🐛 Reportar Bugs
Si encuentras un error, por favor abre un "Issue" describiendo:
1. Qué estabas haciendo.
2. Qué esperabas que pasara.
3. Qué pasó realmente.
4. Capturas de pantalla si es posible.

### 💡 Sugerir Mejoras
Si tienes una idea para mejorar el proyecto, abre un "Issue" con la etiqueta `enhancement` o `feature request` explicando tu idea.

### 💻 Enviar Cambios (Pull Requests)
1. Haz un **Fork** del repositorio.
2. Crea una nueva rama (`git checkout -b feature/mi-nueva-funcionalidad`).
3. Haz tus cambios y commitea (`git commit -m 'Agrega nueva funcionalidad X'`).
4. Haz Push a tu rama (`git push origin feature/mi-nueva-funcionalidad`).
5. Abre un **Pull Request** en este repositorio.

## Estilo de Código
Trata de mantener el estilo de código existente (PHP, HTML, CSS). Si es posible, comenta tu código donde sea necesario.

¡Gracias por tu ayuda!
