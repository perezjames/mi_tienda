# Política de Seguridad

## Versiones Soportadas

Actualmente, solo la última versión del proyecto recibe actualizaciones de seguridad.

| Versión | Soportada          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reportar una Vulnerabilidad

Si encuentras una vulnerabilidad de seguridad, por favor **NO** abras un issue público.

En su lugar, por favor envía un correo electrónico a [tu-email@ejemplo.com] con los detalles. Trataremos de responder lo antes posible y lanzar un parche si es necesario.

¡Gracias por ayudar a mantener este proyecto seguro!
